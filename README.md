# HAWKS VERSE

Free Fire Paid Matches, Scrims and Tournament Platform

## Setup

npm install
npm run dev
npm run build

## Deploy to Vercel

1. Push to GitHub
2. Go to vercel.com
3. Import your repo
4. Framework = Vite
5. Click Deploy

## Features

- Paid Matches (Solo, Duo, Squad)
- Tournaments with prize pools
- Kill-based Scrims
- Player Leaderboard
- UPI Payment Flow

Not affiliated with Garena Free Fire.
